### 🔭 核心技术演练项目 (Key Projects)

#### 🤖 **AIOps-Agent-SelfHealing (AI 智能运维与故障全链路自愈平台)**
- **项目定义**: 缝合传统自动化运维工具（Ansible）与大语言模型（LLM）的智能体自愈闭环。
- **演练链路**: `监控源 (Zabbix/Prometheus) 捕获异常指标` ➔ `触发 Webhook` ➔ `激活 AI Agent 联合推理` ➔ `Function Calling 自动调用 Ansible Playbook 清理磁盘/无损滚动重启` ➔ `降低 MTTR`。

#### 🌐 **High-Availability-Cluster (企业级 Linux 高可用集群与自动化部署实训)**
- **项目定义**: 结课成绩 **96分** 的生产级架构高仿真演练。
- **演练链路**: 基于 **OpenEuler** 进行内核调优 ➔ 部署 **Nginx + LVS（DR模式）+ Keepalived** 核心拓扑 ➔ 解决单点故障，保障 **99.99%** 业务连续性 ➔ 利用 Ansible / SaltStack 资源编排实现 IaC 落地。
